# CLI tools

Install via your package manager or the method noted.

## Shell & terminal

| Tool | Description | Install |
|------|-------------|---------|
| [fish](https://fishshell.com) | Shell | `apt install fish` |
| [tmux](https://github.com/tmux/tmux) | Terminal multiplexer | `apt install tmux` |
| [oh-my-posh](https://ohmyposh.dev) | Prompt engine | binary / `curl` |

## File navigation

| Tool | Description | Install |
|------|-------------|---------|
| [eza](https://github.com/eza-community/eza) | `ls` replacement | `apt install eza` |
| [zoxide](https://github.com/ajeetdsouza/zoxide) | Smarter `cd` | `apt install zoxide` |
| [fzf](https://github.com/junegunn/fzf) | Fuzzy finder | `apt install fzf` |
| [yazi](https://github.com/sxyazi/yazi) | Terminal file manager | cargo / binary |
| [fd](https://github.com/sharkdp/fd) | `find` replacement | `apt install fd-find` |

## Text & code

| Tool | Description | Install |
|------|-------------|---------|
| [neovim](https://neovim.io) | Editor (LazyVim) | `apt install neovim` or nightly binary |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | `grep` replacement | `apt install ripgrep` |
| [bat](https://github.com/sharkdp/bat) | `cat` with syntax highlighting | `apt install bat` |

## System

| Tool | Description | Install |
|------|-------------|---------|
| [btop](https://github.com/aristocratsig/btop) | Resource monitor | `apt install btop` |
