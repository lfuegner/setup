# Setup

Personal configuration files and app lists for quick machine setup.

---

## Structure

```
dotfiles/
├── ghostty/          # Ghostty terminal (Linux)
│   └── config
├── fish/             # Fish shell
│   ├── config.fish
│   ├── abbr.fish
│   └── aliases.fish
├── tmux/             # tmux
│   └── tmux.conf
├── nvim/             # Neovim / LazyVim
│   ├── init.lua
│   └── lua/
├── alacritty/        # Alacritty (Windows)
│   └── alacritty.toml
├── apps/
│   ├── cli.md        # CLI tools reference
│   ├── gui.md        # GUI apps reference
│   └── fonts.md      # Fonts
└── README.md
```

## Apps

See [`apps/cli.md`](apps/cli.md) for CLI tools and [`apps/gui.md`](apps/gui.md) for GUI apps.
